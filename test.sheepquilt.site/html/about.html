Architecture

Structure and presentation stay separate.

HTML describes the content, base CSS provides the system, theme CSS provides the visual identity, and JavaScript provides small enhancements.

HTML

Content layer

Use semantic elements and simple component classes. The document should remain meaningful without CSS.

CSS

Presentation layer

Base CSS owns layout and reusable components. Themes override variables and visual details.

JS

Behavior layer

JavaScript handles navigation injection, theme persistence, mobile navigation, and the demo form.

0 DEP

No dependencies

Everything runs directly in the browser. There are no imports, frameworks, or package dependencies.

Theme architecture

Every page loads the shared base stylesheet first and one theme stylesheet second. The later stylesheet can customize the visual layer without replacing the system.

<link rel="stylesheet" href="css/base.css">
<link id="theme-stylesheet" rel="stylesheet" href="css/themes/minimal.css">

Adding a fifth theme means adding a CSS file and one entry to the JavaScript theme map. Page markup does not need to change.
